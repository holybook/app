# Holybook

The `holybook` MCP server gives access to the authoritative Bahá'í writings (Bahá'u'lláh, the Báb,
‘Abdu'l-Bahá, Shoghi Effendi, the Universal House of Justice and official compilations) in several
languages.

- For questions about the Bahá'í writings, teachings, laws or institutions, activate the
  `bahai-writings-research` skill: search with `search_writings`, read context with
  `get_passage`, and answer with verbatim, cited quotations — never quote from memory.
- When translating a text that quotes the writings, activate the `bahai-quote-translation` skill:
  look up every quotation with `find_authoritative_translation` and use the authoritative
  translation verbatim; mark your own translations of quotations as provisional.
